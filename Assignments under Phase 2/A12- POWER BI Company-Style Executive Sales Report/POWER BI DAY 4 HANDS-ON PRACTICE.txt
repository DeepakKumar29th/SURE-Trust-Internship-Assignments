POWER BI DAY 4 HANDS-ON PRACTICE
Topic: Production Readiness, Security, Refresh, Governance, QA Testing, and Final Project Explanation

Objective:
In Day 1, we built the model foundation and executive summary page.
In Day 2, we added DAX-based profitability and discount analysis.
In Day 3, we added drillthrough, tooltips, bookmarks, navigation, and performance checking.

In Day 4, we will make the report production-ready by adding:
1. Report health measures
2. Data quality monitoring page
3. Row-Level Security role testing
4. Final QA checklist page
5. Report guide page
6. Refresh readiness note
7. Publishing and sharing checklist
8. Interview-ready project explanation page
9. Final end-to-end user testing

By the end of Day 4, your Power BI report should look like something that can be explained in a company project discussion or interview.

PART 3: CREATE RECORD COUNT MEASURE
------------------------------------------------------------

1. In the Fields pane, click the _Measures table.

2. Go to the top ribbon.

3. Click Table tools.

4. Click New measure.

5. Paste this DAX formula:

Record Count =
COUNTROWS(FactSales)

6. Press Enter.

Reason:
This tells how many rows are available in the fact table.


------------------------------------------------------------
PART 4: CREATE DATA START DATE MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Data Start Date =
MIN(DimDate[Date])

4. Press Enter.

Reason:
This tells the earliest date available in the report data.

------------------------------------------------------------

1. Click the _Measures table.

4. Press Enter.

This tells the latest date available in the report data.


------------------------------------------------------------
PART 6: CREATE DATA RANGE MESSAGE MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Data Range Message =
"Data period: "
    & FORMAT([Data Start Date], "dd-mmm-yyyy")
    & " to "
    & FORMAT([Data End Date], "dd-mmm-yyyy")

4. Press Enter.

Reason:
This creates a readable data period message for users.


------------------------------------------------------------
PART 7: CREATE LAST REFRESH MESSAGE MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Last Refresh Message =
"Last model refresh/open time: "
    & FORMAT(NOW(), "dd-mmm-yyyy hh:mm AM/PM")

4. Press Enter.

Reason:
This gives users a visible freshness indicator.

Note:
In Power BI Desktop, NOW() updates when the model recalculates or refreshes.
In Power BI Service, it reflects refresh behavior based on the semantic model refresh.

PART 11: CREATE LOSS MAKING ROW COUNT MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Loss Making Row Count =
CALCULATE(
    COUNTROWS(FactSales),
    FactSales[Profitability Band] = "Loss Making"
)

4. Press Enter.

Reason:
This counts records that are loss-making.

PART 13: CREATE LOSS MAKING SALES MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Loss Making Sales =
CALCULATE(
    [Total Sales],
    FactSales[Profitability Band] = "Loss Making"
)

4. Press Enter.

Reason:
This calculates sales value coming from loss-making records.


------------------------------------------------------------
PART 14: CREATE HIGH DISCOUNT PROFIT MARGIN % MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

High Discount Profit Margin % =
DIVIDE(
    [High Discount Profit],
    [High Discount Sales]
)

4. Press Enter.

Reason:
This checks whether high-discount transactions are still profitable.


------------------------------------------------------------
PART 15: CREATE REPORT QA STATUS MESSAGE MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Report QA Status Message =
VAR LowMarginShare = [Low Margin Sales Share %]
VAR HighDiscountShare = [High Discount Sales Share %]
RETURN
SWITCH(
    TRUE(),
    LowMarginShare >= 0.40 && HighDiscountShare >= 0.30,
        "Review urgently: low-margin and high-discount sales are both high.",
    LowMarginShare >= 0.40,
        "Review margin quality: low-margin sales share is high.",
    HighDiscountShare >= 0.30,
        "Review discount strategy: high-discount sales share is high.",
    "No immediate risk flag from margin and discount checks."
)

4. Press Enter.

Reason:
This gives a simple QA-style business warning based on margin and discount risk.
