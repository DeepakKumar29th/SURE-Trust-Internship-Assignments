PART 3: CREATE PROFITABILITY BAND COLUMN
------------------------------------------------------------

1. In the Fields pane, click the FactSales table.

2. Go to the top ribbon.

3. Click Table tools.

4. Click New column.

5. Paste this DAX formula:

Profitability Band =
VAR RowMargin = DIVIDE(FactSales[Profit], FactSales[Sales])
RETURN
SWITCH(
    TRUE(),
    FactSales[Profit] < 0, "Loss Making",
    RowMargin < 0.10, "Low Margin",
    RowMargin < 0.20, "Medium Margin",
    "High Margin"
)

6. Press Enter.

Reason:
This creates a row-level business classification. Each sales row is classified as Loss Making, Low Margin, Medium Margin, or High Margin.


------------------------------------------------------------
PART 4: CREATE DISCOUNT STRATEGY BAND COLUMN
------------------------------------------------------------

1. Click the FactSales table again.

2. Go to Table tools.

3. Click New column.

4. Paste this DAX formula:

Discount Strategy Band =
VAR RowDiscountRate = DIVIDE(FactSales[Discounts], FactSales[Gross Sales])
RETURN
SWITCH(
    TRUE(),
    FactSales[Discounts] = 0, "No Discount",
    RowDiscountRate <= 0.05, "Low Discount",
    RowDiscountRate <= 0.15, "Medium Discount",
    "High Discount"
)

5. Press Enter.

Reason:
This creates a row-level discount category. It helps analyze whether discounting is controlled or aggressive.


------------------------------------------------------------
PART 5: CREATE SALES LAST YEAR MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Go to Table tools.

3. Click New measure.

4. Paste this DAX formula:

Sales Last Year =
CALCULATE(
    [Total Sales],
    SAMEPERIODLASTYEAR(DimDate[Date])
)

5. Press Enter.

Reason:
This measure calculates sales for the same period in the previous year.


------------------------------------------------------------

------------------------------------------------------------
PART 22: CREATE BUSINESS COMMENTARY MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Business Commentary =
VAR MarginValue = [Profit Margin %]
VAR DiscountValue = [Discount Rate %]
RETURN
"Margin: "
    & FORMAT(MarginValue, "0.00%")
    & " | Discount: "
    & FORMAT(DiscountValue, "0.00%")
    & " | "
    & SWITCH(
        TRUE(),
        MarginValue < 0.10 && DiscountValue >= 0.15,
            "Action: Review pricing and discount strategy immediately.",
        MarginValue < 0.10,
            "Action: Margin is weak. Review cost and pricing.",
        DiscountValue >= 0.15,
            "Action: Discount pressure is high. Check whether discounts are improving profit.",
        "Action: Performance is currently stable."
    )

4. Press Enter.

Reason:
This creates an automatic business interpretation based on margin and discount values.
