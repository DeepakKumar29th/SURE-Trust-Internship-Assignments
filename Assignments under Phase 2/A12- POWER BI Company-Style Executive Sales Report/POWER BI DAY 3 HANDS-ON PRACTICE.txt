PART 3: CREATE HIGH DISCOUNT SALES SHARE MEASURE
------------------------------------------------------------

1. In the Fields pane, click the _Measures table.

2. Go to the top ribbon.

3. Click Table tools.

4. Click New measure.

5. Paste this DAX formula:

High Discount Sales Share % =
DIVIDE(
    [High Discount Sales],
    [Total Sales]
)

6. Press Enter.

Reason:
This measure shows how much of total sales is coming from high-discount transactions.


------------------------------------------------------------
PART 4: CREATE LOW MARGIN SALES MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Low Margin Sales =
CALCULATE(
    [Total Sales],
    FactSales[Profitability Band] = "Low Margin"
)
+
CALCULATE(
    [Total Sales],
    FactSales[Profitability Band] = "Loss Making"
)

4. Press Enter.

Reason:
This measure calculates sales coming from loss-making and low-margin transactions.

------------------------------------------------------------
PART 6: CREATE PRODUCT DETAIL HEADING MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Product Detail Heading =
"Product Detail: "
    & SELECTEDVALUE(
        FactSales[Product],
        "Right-click a product and drill through"
    )

4. Press Enter.

Reason:
This measure creates a dynamic title for the product drillthrough page.


------------------------------------------------------------
PART 7: CREATE PRODUCT RISK MESSAGE MEASURE
------------------------------------------------------------

1. Click the _Measures table.

2. Click New measure.

3. Paste this DAX formula:

Product Risk Message =
VAR MarginValue = [Profit Margin %]
VAR DiscountValue = [Discount Rate %]
VAR LowMarginShare = [Low Margin Sales Share %]
RETURN
SWITCH(
    TRUE(),
    MarginValue < 0.10 && DiscountValue >= 0.15,
        "High risk: weak margin with high discount pressure",
    LowMarginShare >= 0.40,
        "Risk: large share of sales is low-margin or loss-making",
    DiscountValue >= 0.15,
        "Watch: discount pressure is high",
    MarginValue >= 0.20,
        "Good: product margin looks healthy",
    "Moderate: monitor product performance"
)

4. Press Enter.

Reason:
This measure converts product performance into a business-readable message.

END OF DAY 3 POWER BI PRACTICE
------------------------------------------------------------

Main learning:
Day 1 created the model foundation.
Day 2 created the analytical DAX layer.
Day 3 made the report interactive and user-friendly.

A company-ready Power BI report should not only show numbers.
It should allow business users to explore, investigate, drill into details, reset views, and understand performance without asking the analyst every time.

Today’s report helps users:
- move between pages
- drill from product summary to product detail
- hover for extra context
- jump to risky discount scenarios
- reset the page easily
- check report performance
- test interactions before sharing

A dashboard is not finished when visuals are created.
A dashboard is finished only when users can actually use it confidently.
